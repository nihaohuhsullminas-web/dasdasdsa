# DSP9AI — Secret Archive

Статический сайт для GitHub Pages.

- `index.html` — исходная главная страница. Её дизайн и разделы сохранены; изменены только переходы в реестр объектов.
- `objects.html` — каталог карточек объектов с поиском.
- `incidents.html` — полный журнал инцидентов с поиском и зелёными карточками; Тимур выделен анимированным огненным эффектом.
- `incidents-data.js` — тексты инцидентов.
- `employees.html` — новый раздел «Сотрудники».
- `dossier.html?id=128` — отдельная страница досье для выбранной карточки.
- `data.js` — данные каталога и тексты досье.
- `assets/` — исходные постеры и приложенные оригинальные документы.
- `css/style.css` — стили главной и реестра; `dossier-style.css` — стили страницы досье.

Откройте `index.html` локально или опубликуйте всё содержимое папки на GitHub Pages. Раздел «Инциденты» добавлен отдельной страницей. «Аномалии» оставлены без изменений.

Примечание: где текст досье ранее был доступен только как краткая расшифровка, он не считается гарантированно дословным; оригинальные файлы сохранены в `assets/`.
